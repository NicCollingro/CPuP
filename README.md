# Computer Physics with Python

A GitHub repository for developing tasks and homework for the **Computer Physics with Python** lecture at Saarland University, WS 2026/2027.

## About the course

Despite the title, this course is **not** a theoretical physics course. The focus is on computing: students take abstracted physics problems and solve them using Python, getting a practical, hands-on glimpse of what's possible with the language — rather than working through physics theory in depth.

Each weekly session is a 1.5h block split into two parts:

- **~20 minutes** — a short introduction to theoretical computer science, focused mainly on the historical side (how the field developed over time)
- **~70 minutes** — students work together on worksheets, applying what they've learned directly in Python

Students also complete regular **homework assignments**, which count toward the *Leistung* (coursework) required for their credit points.

## Structure

The repository is organized into the following folders:

- **`Lecture/`** — Slides and notes for the theoretical background, including the weekly theoretical CS / history segments
- **`Tasks/`** — Assignments and worksheets students work on during the lecture and at home, including graded homework

## For tutors

Tutors have access to this repository to help develop, review, and maintain tasks and homework materials. When adding new content, please follow the existing folder structure above and keep materials consistent in format with what's already there.
